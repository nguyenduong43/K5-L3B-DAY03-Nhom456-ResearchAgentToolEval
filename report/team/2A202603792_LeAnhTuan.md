### 3.3. Tool mới `wiki` (CP3)

- `starter_v0/tools/wiki/tool.py` — hàm `wiki_search(query, lang, max_results)`: gọi MediaWiki Action API (1 request, `generator=search` + `prop=extracts`), trả đoạn mở đầu dạng plain text kèm URL. Không cần API key.
- Item trả về có `title/url/source/summary` giống `lookup` nên đưa thẳng vào `format` được.
- Guardrail cho input xấu từ model: `query` rỗng → error dict, không gửi request; `lang` ngoài enum → về `en`; `max_results` dạng chuỗi/0/quá lớn/không phải số → ép về 1–5. Mọi lỗi (HTTP, timeout, API trả `error`) trả error dict, không raise.
- `starter_v0/tools/wiki/TOOL.md` theo frontmatter contract; đăng ký `"wiki": wiki_search` trong `tools/__init__.py` và khai báo trong `artifacts/tools.yaml` (khi nào dùng: kiến thức nền; khi nào không: tin tức → `lookup`, tweet, paper, URL).
